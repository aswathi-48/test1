Basic Syntax

$(selector).action();

$ → tells the browser you’re using jQuery.

selector → chooses which HTML element(s) you want to work with.

action() → the task you want to do (like hide(), show(), css()).


in body section we can write

<script>
 $("#head").hide();
 </script>

 in this code not work to the head section bcz after html dom updation only jquery code will be executed
 in case we can set that code in the head section then use,

$(document).ready(function(){
    $("#head").hide();
});

this method

$(document).ready(function(){ ... });
This is a special jQuery function.
Run this code only after the HTML document is fully loaded and ready to use.



hide()

Purpose → Makes the element invisible.
How → Changes its CSS to display: none.
Syntax → $(selector).hide();

show()

Purpose → Makes a hidden element visible again.
How → Changes its CSS back to display: block (or original display).
Syntax → $(selector).show();

css()
Purpose → Changes or gets CSS properties.
How → Directly applies inline CSS styles.
Syntax → $(selector).css("property", "value");


css selectors

id , class, tag

   $("#head").hide(); ( using id)
   $(".head").hide(); (using class)
   $("h2").hide();    (using tag)

 2.dblclick
  Purpose: Runs code when the user double clicks an element.

 3.hover
  Purpose: Runs code when the user hover an element.

    Mouse leave
hover Advantage

Advantage: Oru line-il mouse enter and leave action define cheyyam.
Disadvantage: Ithil enter & leave separate aayi use cheyyan pattilla, both together aayi thanne varum.

Ithu two separate events aanu.
Events
mouseenter() → run aakum mouse element-il keriya samayath.
mouseleave() → run aakum mouse element-il ninnu pokumbol.

Hover → Enterum leaveum orumich use cheyyan.
Mouseenter / Mouseleave → Enterum leaveum separate events aayi full control venam engil use cheyyuka.

jQuery- DOM Manipulation
 Get or Set Text
 text() → Get or set element text content.

 Get or Set HTML
 html() → Get or set HTML content (with tags).

 Get or Set Form Values
 val() → Get or set input field value.

 Change Attributes
 attr() → Get or set attribute values.

 Add or Remove Elements

 append() → Add inside end of element.
prepend() → Add inside start of element.
after() → Add outside after element.
before() → Add outside before element.
remove() → Remove element.
empty() → Remove inner content only.
