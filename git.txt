 Git – Detailed Overview
Git oru Distributed Version Control System (DVCS) aanu.

Main features:
Distributed → Ella developers-inum full repo copy kittum (history included).

Version Control → Oru file-ile old version anytime recover cheyyam.

Branching → Parallel development cheyyan easy.

Merge → Branch work combine cheyyam.

Offline work → Internet illathathilum commit cheyyam.

Issues & bug tracking
